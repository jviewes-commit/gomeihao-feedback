# GoMeihao 反馈与社区中心 🇺🇸

[简体中文](README.md) | [English](README-en.md)

欢迎来到 **[GoMeihao（gomeihao.com）](https://gomeihao.com)** 官方公开问题反馈仓库。

GoMeihao（Go 美好）是给**在美国的中国游客和来美探亲的父母**用的免费、离线优先工具：EVUS 与入境海关自查、英文大字出示卡（看病、药房、点餐、出行、住店、警察、紧急）、小费与销售税计算、就医分流、美国/北京双时钟、911 与中国驻美使领馆。首发覆盖加州。

---

## 💡 如何反馈

- 🛂 **纠正入境或政策信息**：[提交政策纠错](https://github.com/jviewes-commit/gomeihao-feedback/issues/new?template=01_policy_correction.md)  
  *EVUS、海关申报、I-94、销售税、交通规则、使领馆领区等。请附官方来源（CBP、USCIS、州政府、中国驻美使领馆）。*
- 🗣️ **纠正或建议出示卡**：[提交卡片反馈](https://github.com/jviewes-commit/gomeihao-feedback/issues/new?template=02_card_content.md)  
  *英文不自然、美国人看不懂、中文释义有误，或你需要却找不到的说法。*
- 🐛 **提交 Bug**：[提交 Bug 报告](https://github.com/jviewes-commit/gomeihao-feedback/issues/new?template=03_bug_report.md)  
  *界面错位、断网打不开、朗读没声音、时间不对、装到主屏幕失败等。*
- 💡 **提出新功能**：[提交功能建议](https://github.com/jviewes-commit/gomeihao-feedback/issues/new?template=04_feature_request.md)  
  *比如想要的新场景、新的州、给父母用更方便的地方。*

不会用 GitHub？可以请子女帮忙提交，或直接用标题写清楚问题，模板里的项目能填多少填多少。

## 🔍 我们怎么核对事实

- 入境、海关和法规类信息只采用官方来源：美国海关与边境保护局（CBP）、USCIS、联邦公报、州政府官网，以及中国驻美使领馆。
- 能否入境以 CBP 官员现场判定为准。GoMeihao 仅供参考，不构成法律或医疗建议。
- 纠错会先对照官方原文核实再上线；应用里每条政策都标有来源和校准日期。

## 🔒 隐私

- **无需注册，没有广告。** 你保存的卡片、清单和设置只留在手机上。
- **只统计匿名访问量**（Cloudflare Web Analytics），不用 Cookie，不跨站追踪。
- **打开过一次即可断网使用**，包括出示卡和紧急电话。
- 请勿在 issue 里贴护照号、签证号、手机号、住址或航班订单号。
- 完整说明：[隐私与安全](https://gomeihao.com/#/privacy)
